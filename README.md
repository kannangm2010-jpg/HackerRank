# HackerRank Python Solutions

This repository is my active code portfolio for HackerRank challenges, focused on building a strong foundation in Python 3 for competitive programming and Olympiad preparation (ZCO and INOI).

## Repository Structure

To keep things organized as the repository grows, solutions are categorized by their HackerRank domain (e.g., `Collections`, `Errors_and_Exceptions`, etc.).

## Code Format

I prioritize clean, readable logic over shortcuts. To make this repository easy to navigate, every `.py` file is completely self-contained. 

At the top of every file, you will find a docstring containing:
* The complete HackerRank problem statement
* The input and output constraints
* The original URL to the challenge

This means you can read the problem and evaluate the solution without ever having to leave GitHub.

## Tech Stack
* **Language:** Python 3
* **Environment:** Visual Studio Code
